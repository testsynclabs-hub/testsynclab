# TestSync Lab — ASAP Client Acquisition Playbook

Website alone rarely closes B2B deals in week 1. Use this outbound + conversion loop daily.

## Offer (say this everywhere)
Free QA audit in 24h → recommend Basic ($999) / Growth ($1,899) / Scale ($2,799).

## Today (Day 1) — do in order
1. Finish LinkedIn invites (you + partner = up to 100).
2. Both partners post personally (not only company page) tagging TestSync Lab.
3. Message 20 warm contacts (ex-colleagues, managers, founders):

```
Hey [Name] — we launched TestSync Lab (monthly QA retainers from $999).
If you know a team struggling with release quality, happy to do a free audit this week.
Link: https://www.testsynclab.com/contact
```

4. Comment thoughtfully on 10 posts from startup founders / CTOs / eng managers (US/CA timezone morning).
5. Email 10 leads manually if you have addresses — same free-audit offer.

## This week
- Post on company page 4x (problem → proof → offer → case-style tip).
- Publish 1 blog already on site to LinkedIn as a document/carousel summary.
- Ask every connection for 1 intro (referrals convert fastest).
- Set Google Business / Search Console later — secondary to outbound now.

## What closes deals faster than SEO
1. Referrals
2. Warm LinkedIn DMs
3. Free audit call
4. Clear pricing page
5. Fast reply (<24h)

SEO/blog compounds in 30–90 days — run it in parallel, but do not wait on SEO to get first clients.
