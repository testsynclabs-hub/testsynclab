## Post 4 — Practical tip (authority)

Before your next release, test these 5 flows first:

1. Auth / login / logout / password reset  
2. Checkout / payment / failed payment  
3. Core create → edit → delete path  
4. Role permissions (what each user should NOT see)  
5. Mobile Safari + one Android browser  

If any of these are flaky, don’t ship “and hope.”
