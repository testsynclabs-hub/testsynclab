# TestSync Lab — Brand Assets

Use these files for website, LinkedIn, Facebook, Instagram, and WhatsApp.

## Files (in `/public/brand`)

| File | Use |
|------|-----|
| `logo-mark.svg` | Favicon source, header mark, app icon (vector) |
| `logo-horizontal.svg` | Website / docs / email signature |
| `logo-icon-1024.png` | LinkedIn / FB / Instagram / WhatsApp **profile picture** (square) |
| `cover-linkedin.png` | LinkedIn company **cover / banner** |

Also:
- Website favicon: static `app/icon.png` + `app/apple-icon.png` (from `logo-mark.svg` — do not replace with generated OG icons)
- Schema / OG logo: `logo-icon-1024.png`

## Recommended uploads

### LinkedIn Company Page
1. Profile logo: `logo-icon-1024.png` (square)
2. Cover image: `cover-linkedin.png` (wide)

### Facebook Page (later)
- Profile: same `logo-icon-1024.png`
- Cover: reuse `cover-linkedin.png` or crop center

### Instagram (later)
- Profile: `logo-icon-1024.png`
- Keep posts blue/white; use mark in corner watermark

### WhatsApp Business (later)
- Profile: `logo-icon-1024.png`

## Brand colors
- Primary blue: `#1D4ED8`
- Deep blue: `#1E3A8A`
- Soft accent: `#93C5FD`
- White: `#FFFFFF`
